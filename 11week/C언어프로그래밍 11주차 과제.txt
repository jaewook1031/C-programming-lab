[문제 2]
다음 C 코드에서 구조체 변수와 구조체 포인터를 통해 멤버에 접근하려고 할 때, 빈칸 (가)와 (나)에 들어갈 연산자가 순서대로 바르게 짝지어진 것은?

--------------------------------------------------
struct Student {
    int id;
    float gradePoints;
};

struct Student student1;
struct Student *ptr = &student1;

student1 ( 가 ) id = 20240001;
ptr ( 나 ) gradePoints = 88.5;
--------------------------------------------------

1) (가) .    (나) ->
2) (가) ->   (나) .
3) (가) .    (나) .
4) (가) ->   (나) ->

[문제 5]
다음 C 프로그램의 실행 결과로 옳은 것은?

--------------------------------------------------
#include <stdio.h>
#include <string.h>

struct Person {
    char name[50];
    int age;
};

void updateAge(struct Person* p) {
    strcpy(p->name, "Yun");
    p->age = 22;
}

int main() {
    struct Person p1 = { "Moon", 25 };
    updateAge(&p1);
    printf("Name: %s, Age: %d\n", p1.name, p1.age);
    return 0;
}
--------------------------------------------------

1) Name: Moon, Age: 25
2) Name: Yun, Age: 22
3) Name: Moon, Age: 22
4) Name: Yun, Age: 25
